    Как получить тренажёр за пять шагов

    1. 1
      Выберите класс и тему

      Список тем собран по учебникам Босовой Л.Л. (5–11), Полякова К.Ю. и Еремина Е.А. (10–11, углублённый) и каталогам «Решу ВПР / ОГЭ / ЕГЭ». Своё задание имеет приоритет над списком. При желании добавьте ссылки на источники заданий.

    2. 2
      Скопируйте промпт

      Кнопка «Скопировать» берёт весь текст с вкладки «Промпт». Обычно это 1–1,5 тыс. токенов — помещается в любое окно чата.

    3. 3
      Отдайте модели

      Вставьте одним сообщением в Claude, GPT, Qwen, Gemini или DeepSeek — через веб-чат или OpenRouter. Ничего не дописывайте: все требования уже внутри.

    4. 4
      Сохраните файл

      Ответ модели сохраните как trainer.html: Блокнот → «Сохранить как» → кодировка UTF-8, тип файла «Все файлы». Откройте двойным кликом — сервер и Node.js не нужны. Собираете сайт — положите файл рядом с index.html.

    5. 5
      Примите работу

      Пройдите чек-лист ниже. Самое важное — вручную пересчитайте 2–3 эталонных ответа и проверьте клик по кнопке «На главную».

    Если код оборвался: напишите модели «продолжи ровно с места обрыва, без повторов» и склейте части в один файл. При большом количестве заданий (сотни) модель почти наверняка отдаст код в несколько сообщений.
    Простой сайт на GitHub Pages: создайте репозиторий → загрузите index.html (главная со ссылками на тренажёры) и файлы тренажёров → Settings → Pages → Deploy from a branch → main → / (root) → Save. Через минуту сайт доступен по адресу https://имя.github.io/репозиторий/. В поле «Адрес главной» укажите index.html — относительная ссылка работает и локально, и на сайте; для тренажёров в подпапке — ../index.html. Главную страницу со списком тренажёров тоже можно сгенерировать этой моделью: попросите «карточки-ссылки на файлы тренажёров в том же стиле».

    Только код

    Если модель любит пояснения, добавьте в конце сообщения: «Ответь только кодом файла, без текста до и после».

    Температура

    Если в интерфейсе есть настройка температуры, поставьте 0.2–0.4: формулировки и эталоны будут стабильнее от запуска к запуску.

    Эталоны — зона риска

    Модели чаще ошибаются в ответах, а не в коде. Пересчитайте несколько заданий вручную до урока и попросите исправить найденное.

    Ссылки на сайте

    На GitHub Pages регистр имён файлов важен: Trainer.html и trainer.html — разные файлы. Называйте файлы латиницей без пробелов и проверяйте кнопку «На главную» уже на опубликованном сайте.
